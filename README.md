# Буква за буквой

Развивающая игра со словами для детей. Один короткий раунд: слово из 4–7 букв, шесть попыток, объяснение буквенных улик и три подсказки. Без персонажей, рекламы, покупок и постоянных сохранений.

Проект реализуется для трека «Игры» HSE × Сбер. Сдаваемый продукт — каталог `game/` с собственными HTML, CSS, JavaScript, SVG и словарём. Android APK — отдельная автономная оболочка для удобной установки; на защите веб-игру следует открыть в неизменённой песочнице организаторов.

Репозиторий по просьбе владельца приватный. Перед сдачей на хакатон его необходимо сделать публичным и добавить ссылку в общую таблицу.

## Запуск

```sh
python3 scripts/serve.py --port 8877
```

Откройте `http://localhost:8877`. Для телефона в той же сети добавьте `--host 0.0.0.0` и используйте адрес компьютера.

## Проверки

```sh
node --test tests/*.test.js
node scripts/validate.mjs
```
