# Буква за буквой

Развивающая игра со словами для детей. Один короткий раунд: слово из 4–7 букв, шесть попыток, объяснение буквенных улик и три подсказки. Без персонажей, рекламы, покупок и постоянных сохранений.

Проект реализуется для трека «Игры» HSE × Сбер. Сдаваемый продукт — каталог `game/` с собственными HTML, CSS, JavaScript, SVG и словарём. В `android/` и `ios/` находятся автономные оболочки с тем же интерфейсом. На защите веб-игру следует открыть в неизменённой песочнице организаторов.

Репозиторий по просьбе владельца приватный. Перед сдачей на хакатон его необходимо сделать публичным и добавить ссылку в общую таблицу.

## Установка

Готовые файлы доступны в [релизах](https://github.com/MattoYuzuru/bukva-za-bukvoy/releases). Для приватного репозитория нужен доступ участника команды.

| Устройство | Способ |
| --- | --- |
| Android | Установить автономный APK; сервер и Google Play не нужны |
| Mac без iPhone | Собрать `ios/` или открыть `.app` из Simulator ZIP в симуляторе Xcode |
| Mac и iPhone | Открыть Xcode-проект, выбрать свою команду подписи и подключённый телефон |
| iPhone без Mac | Получить приглашение TestFlight от команды после её настройки Apple Developer Program |

Архив Simulator и неподписанная сборка для устройства не устанавливаются на iPhone как APK. TestFlight не настроен: нужны учётная запись команды, подпись и загрузка в App Store Connect. Подробности и команды — в [инструкции iOS](docs/Установка%20iOS.md).

## Запуск

```sh
python3 scripts/serve.py --port 8877
```

Откройте `http://localhost:8877`. Для телефона в той же сети добавьте `--host 0.0.0.0` и используйте адрес компьютера.

## Проверки

Полный локальный набор: `python3 scripts/check.py` (Node 24 и Python 3). По отдельности:

```sh
node --test tests/*.test.js
python3 -m unittest discover -s tests -p 'test_*.py'
node scripts/validate.mjs
```

## Поставка

`python3 scripts/package_game.py` создаёт ZIP с `index.html` в корне и JSON с хешами в `artifacts/`. Этот ZIP содержит только файлы игры. Автономные приложения собираются отдельно по инструкциям Android и iOS. Каталог `artifacts/`, SDK, временные сборки и локальные ключи подписи исключены из Git; готовые пакеты прикладываются к релизу репозитория.

Игра не собирает персональные данные и не обращается к внешним сервисам. Прогресс существует только до закрытия страницы.
