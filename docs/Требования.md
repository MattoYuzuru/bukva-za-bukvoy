# Требования и приёмка

Версия 1.0. Решение согласовано владельцем 17 октября 2026: название «Буква за буквой», без персонажей; собственные SVG вместо эмодзи. Основная поставка — веб-игра для трека B «Игры», дополнительная — автономный Android APK.

## Пользователь и цель

Самостоятельная игра рассчитана на читающих детей 8–10 лет. В 6–7 лет предполагается помощь взрослого и короткие слова. Игра не обучает чтению с нуля. Учебная гипотеза: ребёнок замечает результат проверки, сохраняет верную позицию и переставляет найденную букву в новой догадке. Это относится к работе с гипотезами и критическому мышлению; определения дополнительно расширяют словарь. Эффект на детях пока не измерен.

## Поведение

| Код | Требование | Наблюдаемая приёмка |
| --- | --- | --- |
| И01 | Выбор длины 4, 5, 6, 7; по умолчанию 4 | Новый раунд имеет выбранное число клеток; отдельных уровней сложности нет |
| И02 | Шесть проверок слов | Неполный ввод, неизвестное слово и повтор не увеличивают счётчик |
| И03 | Русский алфавит, включая Ё, Й, Ь, Ъ | Все 33 буквы видны на собственной клавиатуре; Ё и Е различаются |
| И04 | Можно исправить любую незакреплённую клетку | Нажатие клетки меняет позицию ввода; стирание пропускает открытую подсказкой букву |
| И05 | Проверка повторяющихся букв учитывает их количество | Сначала отмечаются точные позиции, затем оставшиеся вхождения; лишний повтор серый |
| И06 | Три состояния понятны без цвета | Зелёный, янтарный, серый сопровождаются SVG; у проверенной клетки есть текстовое объяснение по нажатию |
| И07 | Три бесплатные подсказки в любом порядке | Одна случайная ещё не найденная позиция закрепляется; загадка и определение доступны повторно; попытки не тратятся |
| И08 | Доброжелательный финал | Победа и раскрытие ответа показывают слово, определение и вопрос/наблюдение; нет штрафов и красного цвета |
| И09 | Раскрытие требует подтверждения | До подтверждения ребёнок может вернуться; раскрытие не отправляет COMPLETED_EVENT |
| И10 | Можно повторить и выйти | «Ещё слово» даёт следующий ответ той же длины; выбор длины доступен; выход из незавершённого раунда подтверждается |
| И11 | Нет постоянного прогресса | Обновление страницы сбрасывает сеанс; нет междневной серии и обещания восстановления |
| И12 | Звук выключен при запуске | Включается явным действием; есть переключатель; при скрытии страницы звук приостанавливается |
| И13 | Результат можно показать близким | Перед отправкой видна карточка без ответа, внешней ссылки и личных данных; отправка только через SHARING_EVENT |
| И14 | Ошибка загрузки данных не останавливает игру | Через 1,9 с доступен запасной набор из 8 ответов с собственным проверенным словарём догадок |
| И15 | Контент редактируется отдельно | Замена корректного words.json меняет ответы и подсказки без изменения JS/нативного приложения |

Подсказка-загадка заменяет обязательную пословицу: для каждого простого слова трудно подобрать подлинную понятную пословицу без искусственной связи. Формат данных поддерживает необязательное поле `proverb`; в текущем наборе оно не используется. Озвучки слов нет. Системная клавиатура не вызывается; аппаратная кириллическая клавиатура поддерживается.

## Ограничения организаторов

- Собственные HTML/CSS/JS, без библиотек и движков, включая их локальные копии. Нет Backend, аккаунта, внешних API, аналитики, шрифтов, QR, внешних ссылок, iframe и новых окон.
- Все ресурсы относительные и входят в `game/`. Ориентиры: до 5 МБ, первый играбельный экран до 3 с, анимации 60 fps. Измеренный размер и пределы проверки — в `Проверки.md`.
- Android 8+, iOS 15+, телефоны шириной 360–430 логических точек. Основной режим портретный; поворот сохраняет раунд. На малой высоте прокручивается история, клавиатура остаётся доступной.
- Один короткий раунд, ориентир 3–5 минут; нет таймера давления, обязательной длинной серии, случайных призов, покупок, денежных наград и наказания за паузу.
- Нет персонажей, СберКота, любых свинок, чужих брендов, оружия, реалистичного насилия и заимствованных игровых объектов. Возрастная пригодность требует редакторской проверки; название аудитории само по себе не устанавливает официальную маркировку.
- Только существующие события контейнера. Нет чтения профиля, баланса, токенов, банковских или персональных данных. Не запрашиваются камера, микрофон и геолокация.
- Для защиты нужен живой прототип в **неизменённой официальной песочнице на реальном телефоне**, минимум на Android или iOS. Автономный APK и браузер полезны для проверки, но не заменяют это условие.
- Перед сдачей нужны презентация и публичный репозиторий, ссылка в общей таблице. Сейчас репозиторий приватный по прямому решению владельца.

## Что показывать жюри

| Критерий | Вес | Доказательство в продукте |
| --- | ---: | --- |
| Виральность | 30 | Карточка без раскрытия ответа, явное желание показать близким; пользовательский эффект ещё предстоит проверить |
| Соответствие брифу | 25 | Объяснение буквенной улики и её применение в следующей догадке |
| Реализуемость | 25 | Маленькая статическая поставка, отсутствие зависимостей, работа через существующий мост |
| Управляемость контентом | 10 | Отдельный валидируемый JSON, запасной набор, обновление без нативного релиза |
| Подача | 10 | Живой раунд, честный статус проверок, понятная интеграция |

Оценка критерия 0–5 делится на 5 и умножается на вес. Итог члена жюри до 100, итог команды — среднее.

## Расхождения источников

Специальные ограничения трека B приняты поверх общих правил о локальных сохранениях. Разрешённый CDN не нужен: все файлы локальны относительно игры. Старые примеры с персонажами не считаются разрешением использовать их в новом проекте. PDF допускает localhost, но актуальный сайт требует неизменённую песочницу: localhost используется только как адрес файлов. Сдача кода на сайте указана 18 октября до 15:00, в расписании ВШЭ stop-coding в 14:00 МСК; рабочий ориентир — закончить код к 14:00. Закрытое полное ТЗ со СберДиска и уточнения из чата не прочитаны, пределы исследования сохранены в `Источники.md`.
