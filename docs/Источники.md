# Материалы и границы исследования

## Дизайн и сценарии

- [Figma SberKids](https://www.figma.com/design/Dn9afPitsdKxwGMpUvK96Z/SberKids?node-id=0-1): просмотрен общий состав и блок контента с карточкой игры и градиентными действиями. Полный каталог игр по нему не установлен.
- [Видеосценарии](https://files.sberdisk.ru/s/exev0OcwiO2ufKl): просмотрен состав папки и фрагменты игрового ролика с карточкой, «Змейкой» и результатом. Вся видеобиблиотека не просмотрена; это не источник новых технических требований.
- [Подборка организаторов](https://ru.pinterest.com/fluffyrasputin/вшэ-х-kids-хакатон/): доска с объёмными формами и карточками использована как ориентир настроения. Ассеты не копировались.
- [Plasma](https://plasma.sberdevices.ru/): первичный источник контекста дизайн-системы экосистемы. Компоненты и код не включены из-за запрета библиотек.
- [Гайд кнопки Сбера](https://developers.sber.ru/docs/assets/files/button-guideline-aff440fc9b9172b980ca1e2c9de4e3c3.pdf): контекст зелёного цвета. Дизайн игры не объявляется официальным гайдом Kids.

## Аналоги

[Wordle в «Салюте»](https://apps.sber.ru/salute-apps/eca0f91c-ffa7-44e9-9299-93e156fd4933/) уже присутствует в экосистеме Сбера: карточка с возрастом 12+, пятью буквами, шестью попытками и тремя состояниями. Это не подтверждает наличие Wordle внутри Kids. Закрытый полный каталог Kids под детской учётной записью не проверен, поэтому уникальность внутри него не доказана.

[Game Lab](https://skngames.ru/) содержит 16 дополнительных примеров, включая «Взлом сейфа» с похожей логикой позиций. Нельзя считать этот сайт полным текущим каталогом Kids. Из ссылок задания открывались «Один дома» и «Созвездие светлячков», без полного прохождения. Прямое открытие «Змейки» остановилось на ошибке сертификата; защита не обходилась, сценарий смотрели в видеореференсе. [История версий Kids в RuStore](https://www.rustore.ru/catalog/app/ru.sberbank.sberkids/versions) использована для проверки существующих игр.

Отличие нашего решения — объясняемые буквенные улики, исправление догадки, помощь без штрафа и младшая читающая аудитория. Утверждать новую базовую механику или доказанный учебный эффект нельзя.
