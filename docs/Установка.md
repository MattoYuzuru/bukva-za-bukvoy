# Установка на Android

Для обычной игры нужен файл `bukva-za-bukvoy-android.apk` из релиза репозитория. Интернет, учётная запись, карта и сервер не требуются: слова и картинки находятся внутри APK.

1. Скачайте APK на Android-телефон или перенесите его с компьютера.
2. Откройте файл в загрузках. Если Android запросит разрешение на установку из выбранного приложения, разрешите эту установку.
3. Нажмите «Установить», затем откройте «Буква за буквой» с зелёной иконкой Б.
4. Выберите длину и нажмите «Начнём!». Подсказки доступны бесплатно, звук изначально выключен.

Пакет объявляет Android 8.0 как минимальную ОС и использует системный WebView. Нужен актуальный Android System WebView; заводская версия старого телефона может не поддерживать современные веб-возможности. Фактически проверенные версии перечислены в [Проверки.md](Проверки.md).

На Mac APK не запускается как обычное приложение. Для проверки установлен отдельный Android-эмулятор в `.work/` репозитория. Команды воспроизведения и подпись описаны в [Сборка.md](Сборка.md). Для iPhone отдельного установочного файла в этой поставке нет; веб-игра предназначена для запуска внутри официальной iOS-песочницы.

## Файлы для хакатона

- `bukva-za-bukvoy-game.zip` — сдаваемая веб-игра, `index.html` в корне. Распакуйте без изменения относительных путей.
- `official-sandbox-android.apk` — неизменённая официальная Android-песочница. После установки введите адрес размещённой игры. Для телефона в одной сети с Mac порядок запуска сервера находится в README.
- Автономный APK удобен владельцу, но обязательное живое демо на защите проходит в официальной песочнице на реальном телефоне.
- Презентация находится в `docs/защита/`, сценарий — в `docs/Защита.md`.
