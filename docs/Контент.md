# Словарь и редактура

`game/data/words.json` — основной источник ответов и допустимых догадок. В наборе 96 авторских ответов: по 24 на каждую длину 4–7; исходные 80 сохранены, добавлены 16 бытовых загадок о деньгах, безопасности и дружбе. Для ввода догадок принимаются 16 884 слова: 1 656 на 4 буквы, 3 619 на 5, 5 012 на 6 и 6 597 на 7. Массовый список используется только для приёма ввода, примеры анимации берутся исключительно из авторских карточек. В самой игре нет сетевой проверки орфографии и зависимостей.

Расширение воспроизводится командой `python3 scripts/expand_dictionary.py`. Скрипт скачивает `dist/russian_nouns.txt` из закреплённой ревизии `e7d14d32cbf31e01ee195d0c599233d8f6e6af57` проекта [Harrix/Russian-Nouns](https://github.com/Harrix/Russian-Nouns), проверяет SHA-256 `661949699919aa968dd0033f7bdd8abbe4db09d161b565f3f0181283fd0d0da7`, принимает только кириллические слова длиной 4–7 букв, удаляет дубликаты и добавляет вариант с Е для слов с Ё. Исходный список догадок и все основные ответы сохраняются. Приложение использует только локальный JSON и работает offline. Атрибуция и полный текст лицензии MIT находятся в `game/data/dictionary-license.json`.

Скрипт исключает небольшую подборку очевидной ненормативной лексики простым фильтром по фрагментам. Полный возрастной и редакторский аудит массового списка не проводился; в источнике могут оставаться редкие, устаревшие, спорные или неподходящие детям слова, а также словоформы. Перед расширением тем или подсказок требуется отдельная редакторская проверка.

## Формат

```json
{
  "version": "1.0.0",
  "words": [
    {
      "id": "unikalnyy-id",
      "word": "ЛИСА",
      "theme": "Животные",
      "riddle": "Рыжая, с пушистым хвостом, живёт в лесу.",
      "meaning": "Лесной зверь с острой мордочкой и пушистым хвостом.",
      "fact": "Каких ещё лесных зверей ты знаешь?"
    }
  ],
  "accepted": ["ЛИСА"]
}
```

Это сокращённый пример структуры: валидный полный набор обязательно содержит ответы каждой длины 4–7. Проверяйте точные ограничения актуальным валидатором `game/js/content.js`. Поле `proverb` необязательно; допускается только понятная и проверенная пословица с правомерным использованием.

`word` и догадки — прописные русские буквы, Ё сохраняется. Пробелы, дефисы, имена собственные и англоязычные слова не принимаются. Каждый ответ обязан входить в accepted. Идентификаторы и ответы уникальны. Загадка должна описывать слово, а определение — объяснять его без буквального показа ответа. Поле fact может быть безопасным вопросом или наблюдением, а не только научным фактом.

## Изменение

1. Отредактируйте JSON и добавьте новые ответы в accepted.
2. Проверьте возрастную понятность, длину, двусмысленность, Ё/Е и отсутствие брендов/запрещённого контента.
3. Основной набор обновляется без изменения JS. Запасной набор в `content.js` автономен: при ошибке нового JSON он сохраняет прежний проверенный контент. При плановом обновлении резервной версии можно синхронизировать её догадки и два ответа каждой длины; для публикации основного JSON это не обязательно.
4. Запустите `node --test tests/*.test.js` и `node scripts/validate.mjs`.
5. Пройдите по одному новому слову с каждой подсказкой. Затем замените статические файлы на размещении игры. Встроенный автономный APK для обновления файлов нужно пересобрать; серверная игра в официальной песочнице нативного релиза не требует.

В текущем открытии ответы одной длины не повторяются, пока не исчерпан её набор. Новый сеанс начинает выбор заново. Математический алгоритм не гарантирует, что редактор не пропустил редкое слово: перед защитой полезна независимая вычитка взрослым и короткая проба с ребёнком.
