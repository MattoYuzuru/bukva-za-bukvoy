# Проверки версии 1.0

Запись фактически выполненных проверок, 17 октября 2026. Итоговые идентификаторы сборок и хеши находятся в JSON рядом с артефактами. Исходники, окружение и отчёты локальных финальных команд связывает workstation-dev receipt; журналы инструмента не коммитятся.

## Автоматизированное поведение

- 56 тестов Node: логика раунда, повторы букв, ввод и исправление, подсказки, завершение на шестой попытке, раскрытие, объяснения, валидация и сбои контента, события моста, две регрессии UI.
- Проверка матрицы догадок: число exact/present не превышает число соответствующих букв ответа, exact совпадает с позицией; покрыты Ё и повторяющиеся буквы.
- Независимый SRE-прогон: 13 720 пар, 80 раундов по шесть попыток, 480 операций с закреплённой буквой, ограничение событий. Выявлены и исправлены таймер результата при выходе и перехват Enter у обычных кнопок. Добавлены регрессионные проверки.
- Валидатор поставки: синтаксис JS, точка входа, относительные существующие ресурсы, отсутствие внешних зависимостей/URL/эмодзи/постоянных хранилищ, схема обоих наборов, размер до 5 МБ. Два Python-теста проверяют изоляцию ZIP и отказ при изменении исходников во время валидации. Это проверки конкретных правил, не доказательство отсутствия всех возможных дефектов.

В текущем комплекте 9 файлов, 139 542 байт: HTML, CSS, 5 JS-модулей, SVG, JSON. 80 ответов, по 20 каждой длины, 746 догадок. Размер меняется при изменении контента; актуальное значение печатает `node scripts/validate.mjs`.

## Автономный Android APK

Android 16 / API 36, AOSP arm64, Android System WebView 133.0.6943.137, профиль Pixel 5 около 393 точек по ширине. Управление выполнялось через CUA в настоящем окне Android Emulator, без подмены игровых состояний.

- Загрузились ES modules и основной JSON с локального HTTPS origin без INTERNET-разрешения. Ответ ЛУНА с темой «Природа» отсутствует в резервных четырёхбуквенных ответах, что подтверждает загрузку основного набора.
- Пройден раунд СЛОН → ЛУНА: янтарные Л/Н и отсутствующие С/О, затем победа и определение.
- Системная кнопка Back закрыла обучение, показала подтверждение выхода из раунда, затем позволила отменить выход с сохранением поля.
- Новый раунд открыл РЫБА через подтверждение. В logcat два FINISH_EVENT и один COMPLETED_EVENT: раскрытие не стало победой.
- Системный chooser показал PNG и русский текст. Отдельный системный получатель Print прочитал PNG через временное URI-разрешение и показал полный предпросмотр. Печать и отправка людям не выполнялись.
- Аварий AndroidRuntime и ошибки открытия встроенной игры не обнаружены. Эмулятор записал предупреждения EGL о неподдерживаемом контексте и служебном Chromium component directory; отрисовка и проверенные действия работали.

Первый прогон проверял раннюю сборку оболочки и словаря. Официальная песочница закреплённой ревизии собрана без изменений и установлена в эмулятор; её UI-прогон пока не подтверждён. После него добавлены обычные детские догадки и обработка шаринга только текстом при недоступном canvas. Итоговый пакет пересобирается с тем же интерфейсом; метаданные APK фиксируют точные хеши файлов. API 26–32 и минимальная версия WebView ещё не проверены.

## Незавершённые внешние проверки

- Реальный телефон с неизменённой песочницей организаторов — обязательный шаг владельца перед защитой; удалённо доступного физического телефона нет.
- iOS 15 и Android 8 на физических устройствах, актуальный Android System WebView на минимальной ОС.
- VoiceOver/TalkBack, увеличенный системный шрифт и наблюдение с детьми.
- Холодный запуск на мобильной сети, стабильность 60 fps на слабом телефоне. Небольшой размер делает цель правдоподобной, но сетевой SLA не измерен.
- Длительность 3–5 минут и желание поделиться — продуктовые гипотезы, не доказаны автоматическими тестами.

## Короткий ручной прогон перед защитой

1. Открыть игру в официальной песочнице на телефоне. Убедиться, что звук выключен.
2. Пройти обучение, набрать неполное и неизвестное слово, исправить клетку. Попытка не должна теряться.
3. Проверить слово с повтором буквы, нажать серую и янтарную клетки, применить объяснение.
4. Использовать все три подсказки, повернуть телефон, свернуть и вернуть приложение.
5. Дойти до шестой догадки и открыть ответ; затем выиграть новый раунд. В журнале COMPLETED_EVENT должен появиться один раз на открытие, FINISH_EVENT — по разу на законченный раунд.
6. Открыть карточку, вызвать системное меню, проверить картинку и текст без отправки посторонним. Проверить выход и новое открытие с пустым прогрессом.
7. Сделать репозиторий публичным по решению владельца, сверить его доступность без авторизации и добавить ссылку в таблицу. Подготовить живой URL статической игры.
