# Проверки версий 1.0 и 1.1

Запись фактически выполненных проверок, 17 октября 2026. Итоговые идентификаторы сборок и хеши находятся в JSON рядом с артефактами. Исходники, окружение и отчёты локальных финальных команд связывает workstation-dev receipt; журналы инструмента не коммитятся.

## Автоматизированное поведение

- 57 тестов Node: логика раунда, повторы букв, ввод и исправление, подсказки, завершение на шестой попытке, раскрытие, объяснения, валидация и сбои контента, события моста, три регрессии UI.
- Проверка матрицы догадок: число exact/present не превышает число соответствующих букв ответа, exact совпадает с позицией; покрыты Ё и повторяющиеся буквы.
- Независимый SRE-прогон: 13 720 пар, 80 раундов по шесть попыток, 480 операций с закреплённой буквой, ограничение событий. Выявлены и исправлены таймер результата при выходе и перехват Enter у обычных кнопок. Добавлены регрессионные проверки.
- Валидатор поставки: синтаксис JS, точка входа, относительные существующие ресурсы, отсутствие внешних зависимостей/URL/эмодзи/постоянных хранилищ, схема обоих наборов, размер до 5 МБ. Два Python-теста проверяют изоляцию ZIP и отказ при изменении исходников во время валидации. Четыре дополнительных теста iOS проверяют автономный полный словарь без сети, неизменность канонической игры, явный отказ при неподдерживаемом синтаксисе модулей, защиту чужого выходного каталога и запрет символьных ссылок. Это проверки конкретных правил, не доказательство отсутствия всех возможных дефектов.

В текущем комплекте 9 файлов, 141 958 байт: HTML, CSS, 5 JS-модулей, SVG, JSON. 80 ответов, по 20 каждой длины, 746 догадок. Размер меняется при изменении контента; актуальное значение печатает `node scripts/validate.mjs`.

## Автономный Android APK

Android 16 / API 36, AOSP arm64, Android System WebView 133.0.6943.137, профиль Pixel 5 около 393 точек по ширине. Управление выполнялось через CUA в настоящем окне Android Emulator, без подмены игровых состояний.

- Загрузились ES modules и основной JSON с локального HTTPS origin без INTERNET-разрешения. Ответ ЛУНА с темой «Природа» отсутствует в резервных четырёхбуквенных ответах, что подтверждает загрузку основного набора.
- Пройден раунд СЛОН → ЛУНА: янтарные Л/Н и отсутствующие С/О, затем победа и определение.
- Системная кнопка Back закрыла обучение, показала подтверждение выхода из раунда, затем позволила отменить выход с сохранением поля.
- Новый раунд открыл РЫБА через подтверждение. В logcat два FINISH_EVENT и один COMPLETED_EVENT: раскрытие не стало победой.
- Системный chooser показал PNG и русский текст. Отдельный системный получатель Print прочитал PNG через временное URI-разрешение и показал полный предпросмотр. Печать и отправка людям не выполнялись.
- Аварий AndroidRuntime и ошибки открытия встроенной игры не обнаружены. Эмулятор записал предупреждения EGL о неподдерживаемом контексте и служебном Chromium component directory; отрисовка и проверенные действия работали.

Первый прогон проверял раннюю сборку оболочки и словаря. После него добавлены обычные детские догадки, обработка шаринга только текстом при недоступном canvas и исправления адаптации. Итоговый пакет пересобирается из зафиксированного коммита; метаданные APK фиксируют точные хеши файлов. API 26–32 и минимальная версия WebView ещё не проверены.

## Неизменённая официальная песочница

Закреплённая ревизия `1ba091d72e9e0917af70d88319de51522a54f207`, Android API36 на том же эмуляторе. Введён адрес `http://10.0.2.2:8877` экранной клавиатурой, затем проверены:

- загрузка настоящих файлов игры с локального сервера;
- обучение, определение, ввод КРОТ и победа;
- журнал с FINISH_EVENT и COMPLETED_EVENT, оба приняты контейнером без ошибки контракта;
- SHARING_EVENT: системное меню показало текст и PNG, без отправки людям;
- CLOSE_EVENT: две экранные кнопки возврата из результата закрыли игру и вернули форму URL.

При первом запуске обнаружено наложение нативных кнопок на собственную шапку и расхождение media query с видимой геометрией после формы URL. Исправлена только игра: оставлено место под кнопки контейнера, раскладка вычисляется по visualViewport/innerHeight. На реальном окне WebView подтверждено правильное поле и видимость всей клавиатуры. Добавлен регрессионный тест видимой области. Исходники песочницы не менялись.

Системная кнопка Back официального контейнера закрывает WebView по его собственным правилам; подтверждение выхода через `bukva-back` реализовано в автономной оболочке. Перед открытием URL в песочнице рекомендуется скрыть системную клавиатуру формы. Снимки результата, журнала и шаринга сохранены в `экраны/`.

## Автономная iOS 1.1

Реальный запуск через Device Hub Xcode 27.1 на текущем Mac с Apple Silicon. Основной профиль — iPhone 16 с iOS 27.0 (24A434); дополнительно iPhone Duo с iOS 27.1 (24A94425), открытая поза. Управление выполнялось через CUA, без программной подмены игрового состояния.

- На Duo пройден раунд СЛОН → ХЛЕБ с подсказкой значения. ХЛЕБ отсутствует в запасном наборе: использован полный автономный словарь. В native logs по одному FINISH_EVENT и COMPLETED_EVENT.
- На iPhone 16 проверены главный экран, обучение, поле и все 33 клавиши. Буква А сохранилась при переходе портрет → альбомная раскладка → портрет; попытка осталась первой.
- CLOSE_EVENT из главного экрана уничтожил WebView и показал нативную кнопку «Начать снова». Повторное открытие вернуло выбор длины и новое обучение без прежнего раунда.
- Новый раунд открыл ГРИБ через подтверждение. В логах этого профиля один FINISH_EVENT и ноль COMPLETED_EVENT: раскрытие не засчитано как победа.
- SHARING_EVENT открыл настоящий UIActivityViewController с русским текстом. Системный Print Options прочитал PNG и показал карточку на одной странице. Принтер не выбирался, печать и отправка людям не выполнялись.
- Scoped logs приложения не содержат аварий и исключений. Закрытие прежнего WebContent-процесса зарегистрировано как voluntary, служебные GPU/Networking завершились с code 0. При первом запуске симуляторов наблюдался временный пустой экран до завершения загрузки WebKit; повторное открытие загрузилось без поворота. Время холодного запуска не измерялось, цель трёх секунд не подтверждена.

[Hosted CI](https://github.com/MattoYuzuru/bukva-za-bukvoy/actions/runs/39060853794) успешно собрал Simulator arm64+x86_64 и неподписанный продукт устройства arm64 на macOS 15 с Xcode 26.3 (17C529). Он также проверил фактические срезы через lipo. Тесты игры и упаковщиков прошли отдельным workflow: 57 Node и 6 Python.

Установлен именно Simulator ZIP из этого CI. В metadata записан синтетический merge-коммит pull request `b6d938297bc583643cfa616e94df8de70e7490d0`; хеши `gameSha256`, `iosSha256` и распакованных `.app` сверены с исходниками функции iOS из `60cb00aff7f49ea82d7579a4b2e2c33a2a13327c`. Последующие правки командной документации не меняют эти файлы. SHA-256 ZIP и точные сведения приложены к релизу. Локальная компиляция на Xcode 27.1 не заявляется: её ожидающие задачи остановлены до запуска, чтобы не повторять успешную hosted-сборку. Общий heavy lock другой задачи не обходился.

Снимки без обработки получены штатной кнопкой Screenshot в Device Hub: [главный экран](экраны/ios-главный.png), [поворот с сохранённым вводом](экраны/ios-поворот.png), [PNG в Print Options](экраны/ios-шаринг.png).

Это проверка самостоятельной оболочки, а не официальной iOS-песочницы. Физический iPhone, минимальная iOS 15, VoiceOver, весь набор поз Duo и публикация TestFlight не проверялись. Неподписанная сборка для устройства подтверждает компиляцию и не является установочным IPA.

## Незавершённые внешние проверки

- Реальный телефон с неизменённой песочницей организаторов — обязательный шаг владельца перед защитой; удалённо доступного физического телефона нет.
- iOS 15 и Android 8 на физических устройствах, актуальный Android System WebView на минимальной ОС.
- VoiceOver/TalkBack, увеличенный системный шрифт и наблюдение с детьми.
- Холодный запуск на мобильной сети, стабильность 60 fps на слабом телефоне. Небольшой размер делает цель правдоподобной, но сетевой SLA не измерен.
- Длительность 3–5 минут и желание поделиться — продуктовые гипотезы, не доказаны автоматическими тестами.

## Короткий ручной прогон перед защитой

1. Открыть игру в официальной песочнице на телефоне. Убедиться, что звук выключен.
2. Пройти обучение, набрать неполное и неизвестное слово, исправить клетку. Попытка не должна теряться.
3. Проверить слово с повтором буквы, нажать серую и янтарную клетки, применить объяснение.
4. Использовать все три подсказки, повернуть телефон, свернуть и вернуть приложение.
5. Дойти до шестой догадки и открыть ответ; затем выиграть новый раунд. В журнале COMPLETED_EVENT должен появиться один раз на открытие, FINISH_EVENT — по разу на законченный раунд.
6. Открыть карточку, вызвать системное меню, проверить картинку и текст без отправки посторонним. Проверить выход и новое открытие с пустым прогрессом.
7. Сделать репозиторий публичным по решению владельца, сверить его доступность без авторизации и добавить ссылку в таблицу. Подготовить живой URL статической игры.
