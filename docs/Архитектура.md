# Архитектура

Статус: решение принято владельцем 17 октября 2026. Основной продукт — статическая веб-игра. Персонажи исключены, название «Буква за буквой».

## Компоненты

- `game/js/engine.js`: чистая логика раунда, ввод, проверка букв с учётом повторов, подсказка буквы и финальные состояния. Не знает DOM и платформу.
- `game/js/content.js` и `game/data/words.json`: загрузка и проверка редакционного словаря, запасной набор при ошибке данных. Нет сетевой проверки догадок.
- `game/js/app.js`: экраны выбора длины, обучения, игрового поля, помощи и результата; доступность и адаптация к высоте.
- `game/js/icons.js`: собственные SVG по фиксированному набору имён.
- `game/js/bridge.js`: только пять разрешённых событий. COMPLETED_EVENT — не более одного раза за открытие, FINISH_EVENT — один раз за законченный раунд.
- `android/`: автономный контейнер для установки APK. Игра открывается из встроенных файлов, внешние загрузки и переходы запрещены. Контейнер не является официальной песочницей и не заменяет её на защите.
- `ios/`: отдельный UIKit/WKWebView-контейнер для iOS 15+. Собственный Xcode-проект, общий с Android интерфейс игры, локальные ресурсы и системный шаринг. Контейнер также не заменяет официальную песочницу.

## Состояние

Состояние раунда хранится в памяти: ответ, введённые буквы, позиция редактирования, история, открытая подсказкой позиция, использованные подсказки и результат. Состояния: игра, успех, исчерпаны попытки, ответ открыт. Неизвестная догадка, повтор и неполное слово попытку не расходуют.

После исчерпания попыток ребёнок может открыть ответ и получить объяснение. Это законченный раунд, но не самостоятельное успешное решение. Новая игра не сбрасывает защиту от повторной отправки COMPLETED_EVENT в том же WebView.

## Границы доверия

Данные словаря проверяются до использования. Тексты выводятся как текст, пользовательский ввод ограничен русским алфавитом. SVG берутся только из собственного фиксированного каталога. Веб-игра не получает банковские данные и не обрабатывает входящие команды приложения.

Канал: `window.postMessage({ type, ...поля }, "*")`. У шаринга текст и PNG data URL. Контейнер решает, что делать с событием. Никаких новых типов, браузерной вибрации и браузерного шаринга.

## Поставка

`game/` переносится на сервер организаторов как есть. Документация, тесты, Android, исходные презентации и артефакты сборки не входят в бюджет веб-игры. Отдельный ZIP содержит только `game/`.

Первый запуск требует загрузки файлов с размещения. Между открытиями кэш и хранилище песочницы очищаются, поэтому приложение не обещает офлайн-запуск на серверной поставке. Автономный APK содержит те же файлы внутри пакета.

В iOS WebView читает локальный каталог через публичный `loadFileURL`. Чтобы не зависеть от поддержки ES modules и `fetch` у локального origin, сборка iOS преобразует известные модули в замкнутый классический скрипт и встраивает проверенный полный словарь. Преобразование ограничено синтаксисом текущих модулей и должно прекращаться при неподдерживаемой конструкции. Это производный пакет внутри приложения: исходный `game/` и ZIP для организаторов не изменяются. Внешние соединения и навигация оболочке не нужны.

У iOS нет аналога свободно устанавливаемого APK. CI создаёт архив приложения для Simulator и неподписанный архив для проверки компиляции под устройство. Для установки на iPhone требуется подпись: Personal Team из Xcode для личной проверки либо команда Apple Developer Program для TestFlight. Публикация TestFlight выполняется отдельно от обычных проверок, с учётной записью и секретами владельца команды.

## Выбор технологии

Чистый JavaScript выбран по явному требованию трека. DOM и CSS достаточны для буквенного поля, дают семантические кнопки и небольшой размер. Canvas используется только для картинки результата. Сервер, база данных, фреймворк и игровой движок не требуются.

Геометрию адаптации вычисляет fitHeight по видимой области WebView; CSS использует соответствующие классы. Это учитывает изменение высоты после системной клавиатуры. Присутствие уже установленного официального моста используется только для отступа под нативные кнопки, без вызова новых методов и чтения данных приложения.
